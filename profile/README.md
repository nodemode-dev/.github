FormAI, free open-source desktop apps from NodeAgentc, Inc. Also, check out [NodeMode](https://nodemode.ai), our cloud-hosted enterprise platform.

Each Form app does one job well and runs on your own computer: your files stay on your machine. Many of them can also be driven by an AI agent through MCP when you want that, and they work fine without it.

## Get the apps

Download from **[formai.studio](https://formai.studio/apps/)**. Every release is built and signed by [FormCompiler](https://formai.studio/formcompiler/), our public build pipeline. FormPortal installs the apps and keeps them up to date.

| App | What it does |
| --- | --- |
| [FormVis](https://formai.studio/formvis/) | Layered image editing: layers, masks, selections, painting and export |
| [FormCut](https://formai.studio/formcut/) | Video editing: cut, grade, caption and export |
| [FormWav](https://formai.studio/formwav/) | Audio editing: record, edit, repair, mix and export |
| [FormVFX](https://formai.studio/formvfx/) | Motion graphics and visual effects on a layered timeline |
| [FormLit](https://formai.studio/formlit/) | Photo library and raw development |
| [FormEncoder](https://formai.studio/formencoder/) | Convert, compress and export media in batches, with presets |
| [FormPDF](https://formai.studio/formpdf/) | View, comment, fill, sign and edit PDFs |
| [FormDeck](https://formai.studio/formdeck/) | Presentations: build slides, present and export |
| [Form.md](https://formai.studio/formmd/) | Notes, docs and databases built on plain Markdown files |
| [FormPortal](https://formai.studio/formportal/) | One place to install, open and update every Form app |
| [FormTray](https://formai.studio/formtray/) | One dock icon for every Form app: switch, launch and arrange |
| [FormMCP](https://formai.studio/formmcp/) | One MCP server that shows agents every Form app |
| [FormSkills](https://formai.studio/formskill/) | The apps' skills, ready to install into your agent |

More apps are on the way; [formai.studio/apps](https://formai.studio/apps/) shows what is coming next.

## Licences

## Help and contributing

- **Bugs and ideas:** open an issue in the app's repository.
- **Security problems:** report them privately from the repository's Security tab, never in a public issue. Each repository's SECURITY.md says what to expect.
- **Code:** read the repository's CONTRIBUTING.md first.
- **Anything else:** support@nodemode.ai
